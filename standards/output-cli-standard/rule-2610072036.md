# The Rosinfotech Base Standards

## The Output CLI Standard

### Color

#### Rule #2610072036

* Context:

  * Without a fixed palette every tool invents its own color language: green errors, blue warnings, rainbow headers - the output becomes noise;

  * A single hard-coded shade set fails on one of the terminal families: bright shades drown on light backgrounds, basic shades vanish on dark ones;

* Description:

  * The palette is closed - the semantic roles and their shades per terminal theme are declared once, in the table of Case #1;

  * The notation is uniform: the human name and, in brackets, the SGR parameter string the CLI emits (the short codes are the 16-color shades, `38;5;N` is the 256-color extended form);

  * In the light theme the white role mirrors to absolute black (30) - the emphasis maximum on a light background;

  * Nothing prints in bold - the color alone marks the semantic roles;

  * JSON syntax - human mode only:

    * Keys - cyan;

    * String values - green;

    * Numbers, `true`, `false`, `null` - yellow;

    * Punctuation - the text color;

  * Forbidden: blinking, inverse video, background fills, rainbow runs, color as decoration;

  * Introducing a new role or shade requires changing this rule first;

  * The reference implementation of both themes lives in [assets/output-cli-demo.js](/standards/output-cli-standard/assets/output-cli-demo.js) - its `palette` scenario prints the declaration table;

* Benefits:

  * One visual language across all CLIs of the company;

  * Both terminal families stay readable - the theme mapping, not luck, decides the shade;

  * Red always means the same thing - the reader stops scanning for meaning;

* Examples:

  * Case #1 - the palette declaration - the roles and both themes:

    ```text
    Role         Dark                    Light
    -----------  ----------------------  ----------------------
    Heading 1    Bright cyan (96)        Blue (38;5;25)
    Heading 2    Bright white (97)       Black (30)
    Prompt       Bright cyan (96)        Blue (38;5;25)
    Information  Bright cyan (96)        Blue (38;5;25)
    Success      Bright green (92)       Dark green (38;5;28)
    Warning      Bright yellow (93)      Amber (38;5;130)
    Error        Bright red (91)         Red (31)
    Text         Light gray (38;5;251)   Dark gray (38;5;239)
    Hint         Bright black (90)       Gray (38;5;246)
    ```
