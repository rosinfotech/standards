# The Rosinfotech Base Standards

## The Output CLI Standard

### Color

#### Rule #2610072038

* Context:

  * Color is invisible with NO_COLOR, in logs, in diffs and for colorblind readers; a line marked by color alone loses its meaning entirely;

* Description:

  * Color only emphasizes a meaning already carried by a word or a prefix;

  * The categories of a listing are labeled with words, not with color dots or columns;

  * An error printed in red without the `Error:` prefix is a violation;

* Benefits:

  * The output survives NO_COLOR, pipes and screenshots;

  * Accessibility: the meaning does not depend on color perception;

* Examples:

  * Case #1 - a failure marked by color alone:

    * Incorrect (only the red color distinguishes the failed line):

      ```text
      server-a: deployed
      server-b: failed to connect
      server-c: deployed
      ```

    * Correct:

      ```text
      Done: server-a deployed
      Error: server-b: failed to connect
      Done: server-c deployed
      ```

  * Case #2 - categories labeled by color dots:

    * Incorrect:

      ```text
      ● src/cli.ts
      ● src/main.ts
      ```

    * Correct:

      ```text
      Error: src/cli.ts
      Warning: src/main.ts
      ```
