# The Rosinfotech Base Standards

## The Output CLI Standard

### Interaction

#### Rule #2610072056

* Context:

  * A CLI that hangs waiting for input inside a script blocks the pipeline; a prompt without options forces the user to guess the expected answer format;

* Description:

  * An interactive prompt is a question line followed by numbered option lines indented +4 spaces, the default in square brackets;

  * An empty answer selects the default;

  * A prompt in a non-TTY stream is refused with an `Error:` message and exit code 2 - the process never hangs;

  * Where applicable, `--yes` / `--force` flags bypass the prompts;

* Benefits:

  * Scriptable by default: every dangerous action has a bypass flag;

  * The answer format is obvious: pick a number;

* Examples:

  * Case #1 - the prompt anatomy:

    ```text
    Deploy to production?

        1) yes
        2) no

    Choose [1]:
    ```

  * Case #2 - a prompt in a pipeline:

    ```text
    $ mycli deploy | tee deploy.log
    Error: interactive prompt requires a terminal; rerun with --yes
    $ echo $?
    2
    ```
