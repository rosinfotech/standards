# The Rosinfotech Base Standards

## The Output CLI Standard

### Interaction

#### Rule #2610072056

* Context:

  * A CLI that hangs waiting for input inside a script blocks the pipeline; a confirmation forced into a numbered menu hides the actual yes/no decision;

* Description:

  * A confirmation prompt is a single question line ending with `[Y/n]?` - an empty answer selects the default Y;

  * A choice among many positions uses a numeric menu:

    * The question line ends with the disclosure colon `:` - the numbered options are its child items (per [Rule #2609270954](/standards/documentation-standard/rule-2609270954.md));

    * Numbered option lines indented +4 spaces, each closing with the leaf terminator `;` (per [Rule #2610072042](/standards/output-cli-standard/rule-2610072042.md));

    * The choice line `Choose [N]:` with the default in square brackets;

  * A numeric menu never confirms an action - confirmations use `[Y/n]`;

  * All prompt text - the question, the options, the choice line - renders in cyan (per [Rule #2610072036](/standards/output-cli-standard/rule-2610072036.md));

  * A prompt in a non-TTY stream is refused with an `Error.` message and exit code 2 - the process never hangs (per [Rule #2610072032](/standards/output-cli-standard/rule-2610072032.md));

  * Where applicable, `--yes` / `--force` flags bypass the prompts;

  * A command wrapped in make delivers the bypass as an inline environment variable - `make <target> VAR=1` (the wrapper exports the variable) or `VAR=1 make <target>` (the session scope) - the make goal parser cannot carry raw flags to the script, the exported variable is the flag's transport;

* Benefits:

  * Scriptable by default: every dangerous action has a bypass flag;

  * The answer format is obvious: Y/n for decisions, a number for positions;

* Examples:

  * Case #1 - a confirmation:

    ```text
    Deploy to production [Y/n]?
    ```

  * Case #2 - a numeric menu:

    ```text
    Choose the region:

        1) Region EU;
        2) Region US;
        3) Region APAC;

    Choose [1]:
    ```

  * Case #3 - a prompt in a pipeline:

    ```text
    $ mycli deploy | tee deploy.log

    Error. Interactive prompt requires a terminal; rerun with --yes

    $ echo $?
    2
    ```
