# The Rosinfotech Base Standards

## The Output CLI Standard

### Tooling

#### Rule #2610072058

* Context:

  * Hand-written ANSI escapes and per-project color helpers drift away from the palette and the TTY gating;

* Description:

  * Color and output formatting go only through the approved library of the stack:

    * TypeScript / NodeJS - picocolor;

    * Go - fatih/color;

    * Java - JANSI;

  * Raw ANSI escape sequences in application code are a violation;

  * The approved list is part of this rule: adding or replacing a library requires changing this rule first;

  * A shared company wrapper library may replace the per-stack list once it exists;

* Benefits:

  * TTY detection, NO_COLOR and CLICOLOR handling come tested from one place;

  * The palette lives in one constants module per project, not in escape sequences;

* Examples:

  * Case #1 - a raw escape in application code:

    * Incorrect:

      ```typescript
      process.stdout.write(`\u001b[31m${message}\u001b[0m\n`);
      ```

    * Correct:

      ```typescript
      process.stdout.write(picocolor.red(message) + "\n");
      ```
