# The Rosinfotech Base Standards

## The Output CLI Standard

### Typography

#### Rule #2610072042

* Context:

  * Mixed bullets, tabs and ad-hoc indentation break alignment in every terminal but the author's one;

* Description:

  * The bullet is a dash with a space: `- `;

  * The top-level list starts at column 0; the nesting step is 4 spaces (0, 4, 8); the depth is at most 3 levels;

  * The terminator discipline of [Rule #2609270954](/standards/documentation-standard/rule-2609270954.md) applies to the runtime output:

    * a leaf item ends with `;`;

    * an item with a nested sublist ends with `:`;

  * One blank line before the positions of every (sub)list and after every (sub)list (per [Rule #2610072044](/standards/output-cli-standard/rule-2610072044.md));

  * Sibling leaf items run dense - no blank lines between them;

  * Numbered items (`1. `, `2. `) are used only for step sequences where the order matters;

  * Tabs are a violation - spaces only;

* Benefits:

  * The indentation step matches the code style (4 spaces) and aligns identically in every terminal;

  * The terminators make the structure scannable: `:` promises children, `;` closes the item;

* Examples:

  * Case #1 - a nested listing:

    ```text
    - server-a:

        - restarted at 12:04;
        - uptime 3m;

    - config:

        - updated 2 keys:

            - log level to warning;
            - cache ttl to 300s;

        - backup created;
    ```

  * Case #2 - dense leaf items and a `:` parent:

    ```text
    - migrations: 4 applied;
    - tests:

        - 212 passed;
        - 2 skipped:

            - flaky: auth-login-flow;
            - requires live db: export-import;
    ```

  * Case #3 - a step sequence:

    ```text
    1. fetch the migration list
    2. apply pending migrations
    3. restart the service
    ```
