# The Rosinfotech Base Standards

## The Output CLI Standard

### Interaction

#### Rule #2610072054

* Context:

  * A progress ladder scrolls the whole screen and makes the final verdict unreachable; multi-line redraw breaks in non-TTY consumers;

* Description:

  * A spinner or progress bar occupies exactly one line on stderr, redrawn with `\r`;

  * On completion the line is replaced by the final verdict: `Success: ...` or `Error: ...` (per [Rule #2610072048](/standards/output-cli-standard/rule-2610072048.md));

  * In a non-TTY stream the progress is suppressed entirely; the final verdict is still printed;

  * A step-by-step progress (build, deploy) reports each finished step as one line, never a growing ladder of pending lines;

* Benefits:

  * The terminal shows the process state without scrolling the result away;

  * CI logs get one line per finished step - greppable, not animated;

* Examples:

  * Case #1 - the progress ladder:

    * Incorrect:

      ```text
      Loading...
      Loading...
      Loading...
      Success
      ```

    * Correct (one line redrawn with \r, then replaced):

      ```text
      Fetching migrations... 14/20
      Success: 20 migrations fetched in 2.1s
      ```

  * Case #2 - step progress in CI (non-TTY):

    ```text
    Success: fetch migration list
    Success: apply 4 pending migrations
    Error: migration 2610071900 precondition failed
    ```
