# The Rosinfotech Base Standards

## The Output CLI Standard

### Streams

#### Rule #2610072032

* Context:

  * Scripts and CI wrap the CLI by its exit code: an unstable code convention turns every wrapper into a guess;

* Description:

  * 0 - success, including "no results" answers: an empty result is not an error;

  * 1 - runtime failure: the task was attempted and failed;

  * 2 - usage error: unknown flag, missing argument, missing environment;

  * Exit codes are a machine contract: changing a code requires a major version bump;

  * The process never exits with arbitrary codes: -1 becomes 255 at the shell level, and codes above 128 collide with signal exits;

* Benefits:

  * Predictable wrappers: `mycli deploy && announce` behaves the same everywhere;

  * CI steps fail on real failures, not on empty results;

* Examples:

  * Case #1 - a usage error:

    ```text
    $ mycli deploy --env prod --regoin eu
    Error: unknown flag "--regoin"
    Hint: did you mean "--region"?
    Run "mycli deploy --help" for usage.
    $ echo $?
    2
    ```

  * Case #2 - an empty result is success:

    * Incorrect:

      ```text
      $ mycli search nada
      Error: nothing found
      $ echo $?
      1
      ```

    * Correct:

      ```text
      $ mycli search nada
      No matches
      $ echo $?
      0
      ```
