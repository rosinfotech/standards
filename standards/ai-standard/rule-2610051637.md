# The Rosinfotech Base Standards

## The AI Standard

### AGENTS.md

#### Rule #2610051637

* Context:

  * Paid APIs and MCP services charge silently - an agent without a spend gate drains the balance unnoticed;

* Description:

  * The norm belongs to the Harness role ([Rule #2610042002](/standards/ai-standard/rule-2610042002.md)) and applies to every paid interaction - of the platform itself and of every agent it spawns;

  * When an agent works with a paid service (through an API or MCP), before EVERY paid action it reports:

    * the current balance of the service;

    * the predicted charge of the action;

  * The balance report is always shown - even when the action needs no approval request (an approval-free action still reports);

  * A paid action requires an approval - one of the scopes (a button choice):

    * per action - approve this single call only;

    * per task - approve all the paid actions within the current task;

    * until the end of the current day - approve every paid action until the day ends;

    * full - approve all the further paid actions, no more requests;

  * An already approved scope suppresses only the approval request - never the balance report;

  * The ready-to-copy source of truth is the asset [AGENTS-STANDARD-HARNESS.md](/standards/ai-standard/assets/AGENTS-STANDARD-HARNESS.md);

* Benefits:

  * Spend visibility - every action shows the balance and the price;

  * The engineer picks the friction level - from per-action to full;

  * The balance is never silent.

* Examples:

  * Case #1 - no approval yet:

    * an MCP image generation costs $0.04, the balance is $12.30;

    * the agent reports both numbers and asks (buttons): action / task / day / full;

  * Case #2 - inside an approved scope:

    * the task scope is already approved;

    * the agent still reports the balance and the predicted charge of every action - but asks nothing.
