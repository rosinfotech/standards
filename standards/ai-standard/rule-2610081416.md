# The Rosinfotech Base Standards

## The AI Standard

### AGENTS.md

#### Rule #2610081416

* Context:

  * Agents of other roles also touch CLIs: a backend engineer adds a command, a frontend engineer wraps a build tool; without a binding norm each role applies its own output habits;

* Description:

  * Any agent task that produces or changes a command-line interface follows the Output CLI Standard regardless of the active role;

  * The minimal binding set - respected by every CLI change even outside the CLI Engineer role:

    * streams: stdout for results, stderr for diagnostics - [Rule #2610072030](/standards/output-cli-standard/rule-2610072030.md);

    * exit codes 0 / 1 / 2 - [Rule #2610072032](/standards/output-cli-standard/rule-2610072032.md);

    * color gating and the closed palette - [Rule #2610072034](/standards/output-cli-standard/rule-2610072034.md), [Rule #2610072036](/standards/output-cli-standard/rule-2610072036.md);

    * message prefixes and layout - [Rule #2610072048](/standards/output-cli-standard/rule-2610072048.md);

    * machine-readable modes - [Rule #2610072052](/standards/output-cli-standard/rule-2610072052.md);

  * The typography rules apply to human-facing report output - [Rule #2610072040](/standards/output-cli-standard/rule-2610072040.md), [Rule #2610072042](/standards/output-cli-standard/rule-2610072042.md), [Rule #2610072044](/standards/output-cli-standard/rule-2610072044.md), [Rule #2610072046](/standards/output-cli-standard/rule-2610072046.md);

  * Before reporting completion the change is verified in both modes - a TTY run and a piped or NO_COLOR run per [Rule #2610072034](/standards/output-cli-standard/rule-2610072034.md);

* Benefits:

  * CLI output stays uniform no matter which role produced it;

  * The dual-mode verification catches the classic failures - escapes in pipes, diagnostics on stdout - without a dedicated reviewer;

* Examples:

  * Case #1 - a backend engineer adds a migration command:

    * the result list goes to stdout, the progress and verdicts to stderr - [Rule #2610072030](/standards/output-cli-standard/rule-2610072030.md);

    * a failed migration exits 1, an unknown flag exits 2 - [Rule #2610072032](/standards/output-cli-standard/rule-2610072032.md);

    * verified: `mycli migrate | cat` shows a clean report, `NO_COLOR=1 mycli migrate` shows no escapes;

  * Case #2 - out of scope of this rule:

    * a library function returning structured data - not a CLI; the rule does not apply;
